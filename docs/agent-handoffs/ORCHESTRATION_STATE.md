| What could not be measured here, and the recipe that would | Pinning the blocking frame needs a native stack -- `py-spy dump`, `gdb`, or `/proc/<pid>/task/*/stack`. The measurement therefore has to happen **inside one call**: start the suite, `sleep` past the hang point, then read `/proc/<pid>/task/*/{stat,wchan,syscall}` or `py-spy dump --pid` in the same invocation.
